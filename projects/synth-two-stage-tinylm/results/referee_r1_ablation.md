## What changed
- `src/train.py`: new flag `--lr_schedule {global,per_phase}`, default `global` (unchanged behaviour). `per_phase`
  restarts the same warmup(5%)+cosine (min ratio 0.1) at each plan phase. Phase boundaries are at
  floor(cumulative phase windows / bs); for S-R at 4M they are [0, 512, 1024]. So each phase gets 26 warmup steps and
  decays to 3e-4 at its own end (step 511, then step 1023). `lr_schedule` enters HASH_ARGS only when it is not the
  default, so existing run hashes are unchanged. The unit check (`results/referee_r1/check_lr_schedule.py`, output in
  `check_lr_schedule.txt`) confirms the default hash equals the committed S-R_N4M_s0 run_hash.
- `src/make_plans.py` now also writes `A_real-only-2N_N*.json` and `A_real-only-2ep_N*.json`, and takes an optional output
  dir. I regenerated all plans into /tmp/plans_regen and cmp'd them against the committed `plans/`: all 15 files are
  byte-identical, so `plans/` was not overwritten.
- `src/run_familyB.sh` line 2 comment fixed: 2ep is exactly 2N tokens (N real x 2 epochs) with no cap; only
  real-only-2N is capped.

## Notes (honest)
- Schedule-tail confound: with per-phase restarts, the real phase of S->R gets its own full warmup+cosine. That gives a
  slightly *lower* ppl than the global schedule (mean 15.96 vs 16.12). It is lower on all 3 seeds, but the gap is
  small next to the seed spread (s2 contributes most of it). S-R-perphase is still about 1.4 ppl better than mixed
  (17.39). So the S->R > mixed ordering effect does not come from S->R's real phase sitting in a lower-LR tail;
  giving it a fresh schedule does not hurt it. S-R-perphase is still about 0.8 ppl worse than real-only-2ep (15.18),
  so the matched-total-token conclusion is unchanged. I ran no bootstrap CI here; n=3 seeds.
- Caveat: `mixed` has a single phase, so per_phase is identical to global for it. There is no "per-phase mixed"
  counterpart, and that is the design: the comparison asks whether S->R's advantage depends on its LR tail.
- LR 1e-3 (seed 0 only): every arm is much worse than at 3e-3 (about 22-23 vs 15-17 ppl), which fits the earlier R_dev
  LR choice (results/lr_dev.json). The ranking real-only-2ep (21.99) < S-R (22.19) < mixed (22.88) matches the 3e-3
  ranking, but the gaps are smaller (0.20 and 0.69 ppl) and there is only one seed. That is indicative, not significant.
- Not done: the 1e-3 rows for seeds 1-2, the per-phase schedule for R-S or mixed-realtail, and LRs above 3e-3.
